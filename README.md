=====PYTHON GROCERY STORE=====
A beginner Python project built while learning python fundamentals.

---FEAUTURES---
- Display available products and prices
- Add products to cart
- Add multiple products
- View cart
- Remove products from cart
- Calculate total price
- Main menu with number or text choices
- Empty cart handling
- Exit option

---CONCEPTS USED---

- Variables and data types
- Strings and string methods
- Lists
- Dictionaries
- `if / elif / else`
- `for` loops
- `while` loops
- Functions
- Function arguments and return values
- `break`
- Basic list and dictionary operations

---CURRENT VERSION---

v1.0 — Basic terminal-based grocery store
